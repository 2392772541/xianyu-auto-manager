# 闲鱼素材下载器

双击上一级的 `启动下载器.cmd`，或在本目录执行 `npm start`。界面：http://127.0.0.1:8792 。运行需要 Node.js 和已安装的 Google Chrome。

## 使用

1. 点击「打开闲鱼 / 登录」，在程序专用 Chrome 窗口手动登录。日常 Chrome 和 Codex 右侧的登录不会自动共享。
2. 粘贴网页版商品长链接，每行一条，最多20条。点击开始后串行处理。
3. 结果可复制文案、预览图片、下载 ZIP、打开文件夹。
4. 登录或验证失败时，在采集窗口人工处理后点击重试。重试重新采集并另存版本，不覆盖旧文件。

备用：展开「已登录浏览器备用采集入口」，将采集链接拖到普通浏览器书签栏；在登录的闲鱼商品页点击该书签，将商品资料带回工具，确认后下载。该书签入口尚未在用户浏览器书签栏端到端验证；JSON导入入口已用真实四图商品验证。网页脚本策略可能限制书签运行。

## 已实现

- 网页长链接及分享文本中的长链接；商品ID去重、小批量串行队列。
- 商品正文、图集顺序及高清候选选择；排除推荐图；图片解码和SHA256检查。
- TXT、JSON、图片及ZIP；失败明细、原始图集位置映射。
- 本机持久化队列；中断任务标为失败，人工重试；不同采集时间各存一份。
- 本地服务仅监听127.0.0.1，并检查写入来源与Host；账号配置不导出。

备用真实页面读取 → JSON导入 → 在线下载 → 预览 → TXT/JSON/ZIP 已跑通，4张图片成功，尺寸1080×1368、980×1920、984×1920、988×1920。由于网页「展开」触发下载APP提示而非确认全文展开，结果如实显示待核对。当前可保存已加载的正文，不保证APP专有内容可取得。

首版不支持短链接、仅口令、任意网站、自动绕过验证、视频、自动上架、修改文案或图片；不承诺所有商品可读。价格字段和预览HTML尚未实现。队列用本机JSON原子保存，暂未引入SQLite。

## 文件

- `../商品素材/下载器/`：归档文件，可长期保存。
- `.local/browser/`：专用登录配置，勿分享。
- `.local/jobs.json`：本地任务记录。
- `npm test`：核心验收测试；`npm audit`：依赖检查。

完整成功要求：非空正文、图集数量匹配、图片全部成功且已确认展开。只有图片成功而正文完整性不明时标记待核对。

## 独立 Windows 软件

提供自带 Electron 和 Chromium 的便携 EXE，见 EXE使用说明.md。运行 npm run pack 后生成在 dist，复制该 EXE 即可在 Windows 10/11 x64 运行。npm start 入口继续保留。

打包验证：先用 FISH_SMOKE_DIR 指定空目录启动软件，再运行 node smoke-packaged.mjs <测试目录>。该脚本用既有本地商品样本检查空任务起始状态、内置浏览器、真实图片下载、解码和 ZIP。样本与测试脚本均不分发。登录后直接链接采集仍需要人工登录验收。
